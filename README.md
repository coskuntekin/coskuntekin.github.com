# Personal Blog and Portfolio

This is the source code for [coskuntekin.com](https://www.coskuntekin.com), a personal blog and portfolio powered by [Jekyll](http://jekyllrb.com/).

## Features

- **Static Blog:** Built with Jekyll, using the Minima theme.
- **Posts:** Technical articles on frontend development, Ruby, Middleman, Sass, Node.js, and more.
- **Custom Pages:** About, Categories, 404, and more.
- **Sass & Assets:** Custom styles and images.
- **SEO & Feed:** Sitemap, webmanifest, and Jekyll Feed plugin.
- **Social Integration:** GitHub, Twitter, LinkedIn links.
- **Custom Domain:** [coskuntekin.com](https://www.coskuntekin.com)

## Directory Structure

- `_posts/` — Blog posts (Markdown)
- `_layouts/`, `_includes/`, `_sass/` — Jekyll theme and style customization
- `assets/`, `images/` — Static assets
- `about.md`, `categories.html`, `index.html` — Main site pages
- `404.html`, `sitemap.xml`, `site.webmanifest` — Utility/meta files
- `Gemfile`, `Gemfile.lock`, `.ruby-version` — Ruby/Jekyll dependencies
- `_config.yml` — Jekyll configuration

## Getting Started

1. **Install dependencies:**
   ```sh
   bundle install
   ```
2. **Run locally:**
   ```sh
   bundle exec jekyll serve
   ```
3. **Visit:** [http://localhost:4000](http://localhost:4000)
